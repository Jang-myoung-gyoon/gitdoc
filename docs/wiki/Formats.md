# 포맷 지원표

[처음으로](Home.md) · [데스크톱 메뉴](Desktop.md)

표에 있는 형식은 원본 보관과 버전 관리를 지원합니다. **빈 문서** 열은 **main**의 데스크톱과 MCP에 적용됩니다.

| 형식 | 보기·비교 | 데스크톱 직접 편집 | 빈 문서 |
| --- | --- | --- | --- |
| HWP·HWPX | rhwp로 페이지 렌더링과 비교 | 문단 편집·찾기·바꾸기, 기본 표·도형. **main**에서 선택 범위·리본·표 구조·서식 지원 확대 | 지원, rhwp 0.9.0 이상 |
| DOC·DOCX | LibreOffice 페이지 비교 | 본문·기본 서식·표·기본 도형. DOCX는 텍스트 목록 편집도 제공 | DOCX |
| PPTX | LibreOffice 슬라이드 비교 | 슬라이드 캔버스에서 텍스트·표 셀·개체와 슬라이드 순서 편집 | 지원 |
| XLSX | 시트 이름·셀 주소 기준 값·수식·일부 서식·병합 비교, PDF 페이지 보기 | 셀 값·수식 수정 또는 지우기 | 지원 |
| PDF | 페이지 및 시각적 변경 비교 | 회전·삭제, 메모, 빈 페이지 또는 다른 PDF의 페이지 삽입 | 지원 |
| XLS·XLSM | 시트 비교·PDF 페이지 보기 | 외부 편집기에서 저장한 파일 제출 | — |
| CSV·TSV | 텍스트 표 비교, 고유 열로 행 맞추기 | 외부 편집기에서 저장한 파일 제출 | — |
| DOCM·PPT·PPTM·ODT·ODS·ODP | LibreOffice 페이지 비교 | 외부 편집기에서 저장한 파일 제출 | — |

## 편집 범위와 저장

- **HWP·HWPX**의 표 셀 내용 편집은 일반 한 줄 텍스트 셀이 대상입니다. 보호·중첩·복합 구조는 명령별로 제한됩니다. 병합 셀을 포함하는 범위는 병합 셀 전체를 선택하세요. **셀 크기**는 열 너비나 행 최소 높이에 적용됩니다. **셀 테두리**는 실선 또는 선 없음, **셀 배경**은 단색을 지원합니다. 공유 경계에는 이웃 셀의 선이 남을 수 있고, HWP에서는 한 번에 최대 100개 셀을 변경할 수 있습니다. 지원되는 본문 도형 이동·크기 편집은 페이지와 문단 배치에 제약이 있습니다.
- **DOC**은 LibreOffice로 DOCX를 거쳐 원래 형식으로 돌아오므로 복잡한 배치나 서식이 달라질 수 있습니다. **DOCM·XLSM·PPTM** 원본은 보관되며 미리보기 변환에 매크로를 실행하지 않습니다.
- **XLSX** 수식의 재계산은 Excel 같은 스프레드시트 편집기의 계산 설정에 따릅니다. **CSV·TSV**는 UTF-8, BOM이 있는 UTF-16, CP949를 지원하며, 이름이 같은 고유 열로 행을 맞출 수 있습니다.
- **PDF**에서 암호가 걸리거나 서명된 파일은 편집이 제한됩니다. 기존 PDF 본문 글자 교체와 개체 편집은 공개 설치본과 **main**의 사용 범위 밖입니다. OCR은 페이지에서 텍스트를 읽는 데 사용됩니다.

문서 **저장**에서 선택한 원본 또는 지원되는 PDF·호환 형식을 내보낼 수 있습니다. 호환 변환은 HWP↔HWPX, DOC↔DOCX, PPT↔PPTX, XLS↔XLSX, 일부 OpenDocument 형식에 제공됩니다. 실행 환경별 지원 목록은 MCP `get_document_capabilities`에서도 확인할 수 있습니다.
