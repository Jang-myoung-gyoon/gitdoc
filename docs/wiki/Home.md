# GitDoc 사용 안내

GitDoc은 문서 원본과 버전 이력을 로컬 문서함에 저장하는 앱입니다. 데스크톱에서 문서를 등록·편집하고, 같은 컴퓨터의 브라우저에서 읽고 비교할 수 있습니다. 로컬 MCP로 에이전트에 검색·비교·수정안 작성 도구를 연결할 수 있습니다.

**2026년 11월 28일 기준** 공개 설치본은 **v0.1.4**입니다. 이 안내에서 **main**으로 표시한 기능은 소스에 병합된 상태입니다. 공개 설치본에서 사용할 수 있는 기능과 검토 단계에 있는 기능은 [릴리스 상태](Release-Status.md)에 정리했습니다. [정식 다운로드](https://github.com/Jang-myoung-gyoon/gitdoc/releases/tag/v0.1.4)

| 하고 싶은 일 | 시작 위치 |
| --- | --- |
| 설치하기, 기존 문서함 유지하기 | [설치와 업데이트](Install-and-Update.md) |
| 파일을 등록하고 버전 만들기 | 데스크톱 **문서함** 또는 MCP `register_document`. [데스크톱](Desktop.md) |
| 빈 문서 만들기 **main** | 데스크톱 **문서함 → ＋ 새 문서** 또는 MCP `create_blank_document`. [데스크톱](Desktop.md) |
| 두 버전의 차이 검토하기 | 데스크톱 **두 버전 비교**, **브라우저에서 보기** 또는 MCP `compare_versions`. [브라우저](Browser.md) |
| 파일을 직접 고치거나 다른 형식으로 저장하기 | [포맷 지원표](Formats.md) |
| 에이전트에 읽기·비교·수정 도구 연결하기 | [MCP와 CLI](MCP-and-CLI.md) |

이 안내의 **브라우저 뷰어**는 GitDoc 데스크톱과 같은 로컬 저장소를 엽니다. 앱, 브라우저, MCP에서 문서 목록이 다르면 표시된 작업 공간 이름과 ID, 실행 환경의 `DOCVERS_DB`를 먼저 확인하세요.
