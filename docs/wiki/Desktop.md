# 데스크톱에서 하는 일

[처음으로](Home.md) · [포맷 지원표](Formats.md)

## 문서함과 버전

1. 기존 파일은 앱의 **문서 등록**으로 가져옵니다. **main**에서는 **문서함 → ＋ 문서 등록**에도 버튼이 있습니다. 최초 확정본은 문서 브랜치 `main`의 `v1.0.0`입니다. 기본 등록 한도는 파일당 30 MiB입니다.
2. 빈 문서가 필요하면 **main**의 **문서함 → ＋ 새 문서**에서 제목과 형식을 선택합니다. DOCX·PPTX·XLSX·PDF·HWP·HWPX를 생성한 뒤 바로 엽니다.
3. **버전 이력 → 문서 보기**로 이전 버전을 열거나 **두 버전 비교**에서 대상을 선택합니다. **이전 변경**, **다음 변경**으로 시각적 차이를 이동할 수 있습니다. **한 버전 보기**로 비교를 닫습니다.
4. 외부 편집기를 쓰는 경우 **원본 다운로드**로 파일을 받아 수정한 뒤 **수정안 제출**로 올립니다. 직접 편집에서는 **수정안 저장**으로 새 버전을 만듭니다.

**설정 → 수정안 검토 사용**을 켜면 이후 데스크톱 수정본이 검토 대기로 저장됩니다. 이력에서 **승인** 또는 **반려**를 선택합니다. 기본 설정에서는 데스크톱 수정본이 바로 확정됩니다. 브랜치는 **브랜치 대조**에서 최신본과 공통 조상을 확인하고 병합합니다. 이전 버전 복원은 그 내용을 새 버전으로 저장합니다. 이력의 우클릭 메뉴에서 브랜치 기준점을 되돌리는 작업은 `recovery-…` 복구 브랜치를 생성합니다.

## 직접 편집 메뉴

| 하는 일 | 최신 확정본에서 여는 곳 |
| --- | --- |
| DOC·DOCX 본문, 표·도형 | **본문 편집**. 본문을 고쳐 저장하거나 **표**, **도형**으로 개체를 삽입합니다. **문서 표**에서 최상위 본문 표를 선택할 수 있고 **도형 서식**에서 지원되는 기존 도형을 고칩니다. |
| HWP·HWPX 본문 | **본문 편집**. **main**의 **편집·서식·입력** 탭에서는 본문에 커서를 놓고 개체를 삽입하거나, 글자를 드래그한 뒤 **글자 색**을 적용합니다. 정렬과 줄 간격은 문단에 적용됩니다. |
| HWP·HWPX 표와 도형 **main** | 셀을 누르거나 **기존 표**로 선택한 뒤 **표 레이아웃**에서 **셀 내용 편집**, **줄/칸 편집**, **셀 합치기**, **병합 셀 나누기**, **행·열로 나누기**, **가로 맞춤**, **세로 맞춤**, **셀 크기**, **셀 테두리**, **셀 배경**을 사용합니다. 본문 도형은 **도형 도구 → 도형 선택**에서 이동·크기를 지정합니다. |
| PPTX 슬라이드 | **슬라이드 편집**에서 글자나 셀을 클릭합니다. 위쪽 도구로 글자 서식을 바꾸고 슬라이드 추가·복제·삭제 및 텍스트 상자·이미지·도형·표 삽입을 합니다. |
| XLSX 셀 | 시트에서 셀을 더블클릭하거나 **셀 수정**을 누른 뒤 값·수식 입력 또는 지우기를 선택합니다. |
| PDF 페이지 | **페이지 도구**에서 **오른쪽 회전**, **왼쪽 회전**, **메모 추가**, **페이지 삽입**, **페이지 삭제**를 선택합니다. **삽입할 PDF 선택**을 건너뛰면 빈 페이지 한 장을 넣습니다. |

**저장**은 선택한 버전을 원본·PDF 또는 지원하는 호환 형식으로 내보냅니다. **인쇄**는 선택한 버전의 시스템 인쇄 창을 엽니다. [포맷별 편집 범위와 제한](Formats.md)
