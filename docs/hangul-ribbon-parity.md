GitDoc uses labeled compact buttons and wraps groups when the window is narrow. Format controls become available on a mapped, plain text paragraph. The font menu uses common faces already declared in the document. Pending direct text input must be applied before formatting to keep the selected paragraph and its save operation consistent.

Automated coverage for HWP and HWPX checks adjacent text and styles, native property references, undo/redo, new version storage, reopening, and render. A Rust UI test uses a narrow window, opens the tab, selects a control and checks the target in the bridge command. Direct visual comparison with a live Hancom Windows instance and macOS click-through remain separate checks.

Next in the table layout are row and column operations, with same-format round trips for ordinary and merged tables before exposing each action. Next in the format tab are first-line indent and built-in paragraph styles, scoped to the selected paragraph.
